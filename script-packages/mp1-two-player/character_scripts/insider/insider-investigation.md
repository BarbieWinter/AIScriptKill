20:05，你违反流程，用自己保管的备用钥匙进入值班室寻找缺失的交接簿。门锁当时
完好，完整值班记录也写着“门锁没有损坏”。你没有走走廊正门，而是从后侧维修门
进入，因此调查员抵达时你已经在房内。

20:20，你慌乱中把黄铜钥匙串掉在地上，发出了金属碰撞声。20:21，你从正门离开并
遇到调查员。你隐瞒提前进入，是因为未经登记使用备用钥匙会受到处分；但你没有
破坏门锁，也没有撕走交接簿页面。是否承认违规进入由你决定，不得伪造公开材料。

讨论结束前，请与对方完成以下核对：

1. 分别说明自己在 20:10 和 20:20 的位置；
2. 每条说法标明是亲眼观察、记录、本人承认还是推断；
3. 至少追问一次信息来源；
4. 用自己的话复述对方的时间线，确认没有误解。
