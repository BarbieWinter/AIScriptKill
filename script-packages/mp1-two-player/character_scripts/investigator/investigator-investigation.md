20:10，你抵达值班室外的走廊登记台，此后一直留在那里。登记台能看清走廊入口和
值班室正门，但看不到房间内部或后侧维修门。20:10 至 20:20 之间，没有人从走廊
进入值班室。

20:21，你亲眼看见知情人从值班室正门出来，右手攥着一串黄铜钥匙。对方看到你后，
立刻把钥匙收进口袋。你没有看见对方何时、从哪里进入，因此不能断言对方破门或
损坏了记录。

讨论结束前，请与对方完成以下核对：

1. 分别说明自己在 20:10 和 20:20 的位置；
2. 每条说法标明是亲眼观察、记录、本人承认还是推断；
3. 至少追问一次信息来源；
4. 用自己的话复述对方的时间线，确认没有误解。
