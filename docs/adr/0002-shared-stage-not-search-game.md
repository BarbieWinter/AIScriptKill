# 地图是共同沉浸舞台，不是搜证主循环

## Context

现有 2.5D Demo 已经提供可走动地图。如果直接以地图热点作为多人主循环，产品会从
传统剧本杀的读本与讨论转向合作探索游戏，并使高频坐标进入玩法授权。

## Decision

多人玩法的核心循环是各自阅读私有角色剧本、在公共文字频道讨论、执行剧本指定的
结算并同步推进。可走动地图保留为玩家共享的沉浸舞台，用于氛围、角色存在感和少量
明确演出交互，但不承担分头探索或自由搜证主循环；公共材料由剧本在确定节点发放。

## Consequences

- 双方可以看到对方角色，但 avatar pose 不是玩法权威。
- 公共线索不依赖自由搜索地图热点。
- 地图的 RAF 移动、碰撞和镜头继续与低频房间状态隔离。

## Scope

特殊剧本未来可以声明少量舞台交互，但必须是明确的 YAML 演出动作，而不是默认搜证。
