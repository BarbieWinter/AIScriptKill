# 前端交互体验设计 (Frontend Experience Design)

> 核心目标：让玩家从"打开网页"到"完成复盘"的每一刻都沉浸在悬疑氛围中。
> 技术栈：Next.js 14+ · shadcn/ui · Tailwind · Zustand · TanStack Query · Howler.js · Konva.js

---

## 1. 设计哲学

### 1.1 三层沉浸法则

```
第一层：环境沉浸
  视觉调性 · 音频氛围 · 过渡动画
  → 玩家意识到"我进入了一个故事"

第二层：叙事沉浸
  角色对话 · 剧情推进 · 线索发现
  → 玩家关心"接下来会发生什么"

第三层：心智沉浸
  推理思考 · 怀疑猜忌 · 反转冲击
  → 玩家在内心说"原来如此！"
```

### 1.2 核心交互原则

| 原则 | 说明 |
|------|------|
| **减少UI存在感** | UI是窗玻璃，不是窗框。玩家应该感觉"在场景中"，而非"在操作界面" |
| **状态即叙事** | 页面状态变化本身就是讲故事——暗下来的灯光、变缓的淡入、突然的静音 |
| **反馈即氛围** | 每次操作都给氛围反馈，不只是"操作成功"——发现证据时的音效、角色紧张时文字变速 |
| **克制胜于丰富** | 每次只给有限的操作选项，不让玩家迷失在按钮海洋中 |
| **可回看但不打断** | 对话历史、线索板可以随时打开，但不应该打断正在进行的剧情演出 |

#### 状态驱动的UI变化

游戏进程不仅仅是内容变化，UI本身也随状态变化：

```yaml
阶段/事件: UI变化
──────────────────────────────────────────
正常调查阶段:    UI明亮（相对），BGM轻柔
                                            
关键线索发现:    屏幕边缘闪白，音效，
                 对话区高亮显示线索文本
            
紧张对峙:        场景变暗（叠加暗色遮罩），
                 BGM变急促，
                 对话文字抖动/渐变色
            
剧情音频播放:     弹出字幕面板，
                 场景锁定（用户可暂停但不可操作），
                 顶部出现进度条
            
恐怖/反转时刻:    场景闪烁，
                 音频突变，
                 对话区突然全红标注
            
结局揭示:        全屏切换为真相展示模式，
                 UI元素几乎全部消失，
                 只有文字+音频流
```

#### 布局适应性

```
桌面端 (1920x1080+):
  场景区占70%高度
  对话区在右下角浮动 400px宽
  热区标签跟随鼠标悬停展开

平板端 (1024x768):
  场景区占60%高度  
  对话区全宽在底部
  热区点击而非悬停

手机端 (375x667):
  场景区占50%高度
  对话区全宽
  操作栏图标化
  侧边面板改为底部弹出式Sheet
```

### 3.7 对话系统设计

对话是交互频率最高的组件，需要精心设计：

```
┌───────────────────────────────────────┐
│                                       │
│  ┌─────────────────────────────────┐  │
│  │ 王大达 · 饭店老板               │  │  ← 角色头+名字
│  │                                 │  │
│  │ "你们可算来了！我都等半天了。"   │  │  ← NPC气泡（左对齐，灰色底）
│  │                   12:30        │  │
│  │                                 │  │
│  │ "你昨晚听到什么奇怪的声音吗？"   │  │  ← 玩家气泡（右对齐，主题色底）
│  │                   12:31        │  │
│  │                                 │  │
│  │ 王大达显得有些不自然             │  │  ← 动作/情绪描述(斜体，居中)
│  │                                 │  │
│  │ 王大达:                        │  │
│  │ "声音？没……没有啊，我睡得很早。"│  │  ← 新回复实时流入
│  │                   12:31        │  │
│  └─────────────────────────────────┘  │
│                                       │
│  ┌────────────────────────────────┐   │
│  │ [输入框...]         [发送]     │   │  ← 输入区
│  │                                │   │
│  │ @王大达 @dm @线索 [出示证物]   │   │  ← 快捷指令
│  └────────────────────────────────┘   │
└───────────────────────────────────────┘

对话增强设计:
├─ NPC说话时头像闪烁/轻微动画表示"正在说"
├─ NPC处于撒谎状态时，文字背景微红
├─ NPC情绪变化时，文字样式变化(颤抖/加粗/变小)
├─ 提及已发现的线索时，线索名高亮可点击
├─ DM的旁白用特殊样式(居中、斜体、分隔线)
├─ 关键对话自动"钉"在对话顶部
├─ 输入支持 @提及角色 / 快捷命令
└─ 可随时查看角色对玩家的"态度值"(隐式的，通过对话语气体现)
```

## 4. 沉浸式交互细节

### 4.1 音频体验设计

```
音频层级(混合播放):
  Layer 0: 环境BGM (始终循环，低音量)
  Layer 1: 场景BGM (按场景切换，中音量)
  Layer 2: 剧情音频 (如有播放，抢占焦点，高音量)
  Layer 3: DM语音 (TTS生成，中音量)
  Layer 4: 音效 (瞬间播放，低中音量)

音频控制面板（底部常驻）:
  [♪] ← 点击展开
  ├─ 总音量:  ████████░░
  ├─ BGM:     ██████░░░░
  ├─ 语音:    ███████░░░
  ├─ 音效:    █████░░░░░
  ├─ [自动播放] [字幕] [仅关键语音]
  └─ 正在播放: 雪乡夜色 - 02:34/04:00
```

### 4.2 过渡动画

```
场景切换:
  旧场景淡出(0.5s) → 黑屏(0.3s) → 新场景淡入(0.8s)

阶段切换:
  顶部横幅滑入"第一幕·第一轮搜证"(停留2s) → 上滑消失

关键发现:
  屏幕边缘闪光(0.2s) → 线索卡片从中心放大出现

情绪突变:
  屏幕色调瞬间偏移(暖→冷) + 四周暗角加深

音频播放:
  顶部下滑出字幕区域(0.3s)
  进度条从0开始填充

反转时刻:
  全屏闪烁 → 切黑 → 新场景(类似电影切镜)
```

### 4.3 微交互（细节决定品质）

```
┌──────────────┬──────────────────────────────┐
│ 交互场景     │ 微反馈                        │
├──────────────┼──────────────────────────────┤
│ 鼠标准入热区  │ 热区发光描边 + 轻微放大      │
│ 点击热区     │ 涟漪动画 + 音效              │
│ 发送消息     │ 消息气泡弹入动画              │
│ NPC正在输入   │ 打字闪烁"..." + 头像脉动     │
│ 新消息到达   │ 底部对话区轻微上弹            │
│ 线索解锁     │ 卡片翻转动画 + 发现音效       │
│ 证物出示     │ 证物飞出到角色头像 + 反馈音效 │
│ 阶段自动保存  │ 右上角闪"已保存"图标(0.5s)   │
│ 提示推送     │ 右下角淡入提示气泡(5s后消失)  │
│ 长按线索关联  │ 连线拖拽动画                 │
│ 提交推理     │ 信封飞入动画 + 等待音效       │
│ 错误操作     │ 按钮抖动 + 红色边框闪现       │
└──────────────┴──────────────────────────────┘
```

### 4.4 加载/等待状态

```
LLM响应等待(最常发生):
  方案A(≤3s): NPC头像"打字中"动画
  方案B(3-10s): 显示"正在思索……" + 随机角色思考表情
  方案C(>10s): "还在回忆中……要不你先看看其他线索？"
               [查看线索板] [查看证物] (不阻塞等待)

音频加载:
  显示加载进度环在音频控制区
  加载完成自动播放（如果设置了自动播放）

页面加载:
  展示当前剧本的海报+名言
  底部加载进度条
  避免空白loading
```

├─ 可调字体大小
├─ 可调动画幅度（减少晕动）
├─ 键盘全操作支持（Tab导航）
├─ 离线中断：保存状态，重连后恢复
├─ 浏览器兼容：降级时保留核心文本体验
├─ 低性能设备：关闭背景动画，降低图片质量
